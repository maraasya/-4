# FinFuture Simulator

FinFuture Simulator — учебное веб-приложение для учёта личных финансов. Интерфейс на русском языке, суммы отображаются в кыргызских сомах (сом).

## Возможности

- Финансовая панель: общий баланс, доходы, расходы и накопления по целям.
- Учёт доходов и расходов: сумма, категория, дата и тип операции.
- Добавление и удаление операций.
- Цели накопления с прогрессом, остатком до цели и приблизительным сроком накопления при ежемесячных взносах.
- Аналитика расходов по категориям.
- Сравнение доходов и расходов за выбранный период.
- Фильтр периода: всё время, последние 7 дней, текущий месяц и текущий год.
- Поиск операций и фильтрация по датам.
- Лимит расходов с предупреждением при достижении 80% и превышении лимита.
- Экспорт операций в CSV.
- Светлая и тёмная темы.
- Сохранение данных в `localStorage`.

## Как запустить локально

1. Скачайте или клонируйте репозиторий.
2. Откройте `index.html` в браузере.
3. Для разработки можно открыть папку проекта в Visual Studio Code и запустить `index.html` через расширение Live Server.

Сборка, сервер и дополнительные библиотеки не требуются. Данные хранятся локально в браузере, поэтому в другом браузере или на другом устройстве они автоматически не появятся.

## Публикация через GitHub Pages

1. Создайте публичный репозиторий с именем `finfuture-simulator`.
2. Загрузите в корень репозитория `index.html`, `style.css`, `script.js` и `README.md`.
3. Откройте **Settings → Pages**.
4. В разделе Build and deployment выберите **Deploy from a branch**.
5. Укажите ветку `main` и папку `/(root)`, затем нажмите **Save**.
6. Дождитесь завершения публикации и откройте адрес, который GitHub Pages покажет в настройках.

## Основные функции JavaScript

- `addTransaction()` — добавляет финансовую операцию.
- `calculateBalance()` — рассчитывает текущий баланс по всем операциям.
- `calculateIncome()` — рассчитывает доходы за выбранный период.
- `calculateExpenses()` — рассчитывает расходы за выбранный период.
- `deleteTransaction()` — удаляет операцию.
- `addSavingsGoal()` — создаёт цель накопления.
- `updateProgress()` — рассчитывает прогресс и примерный срок достижения цели.
- `renderChart()` — строит сравнение доходов и расходов и структуру расходов.
- `saveData()` — сохраняет данные в браузере.
- `exportReport()` — экспортирует операции в CSV.

## Примечание

Это учебный симулятор, а не банковское приложение. Он не подключается к банковским счетам. Баланс рассчитывается как сумма доходов минус сумма расходов; суммы, внесённые в цели накопления, отображаются отдельно и не списываются из баланса автоматически.
